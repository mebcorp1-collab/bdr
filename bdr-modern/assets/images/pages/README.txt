IMAGES PAR PAGE (surcharge facultative)
=======================================
Par défaut, chaque page utilise une photo du dossier ../photos/ (voir bdr_v15_photo_map dans inc/bdr-v15-ui.php).
Pour donner une photo propre à une page : déposez ici <slug>.webp (+ <slug>-800.webp), 1600 x 900 px, moins de 200 Ko.
Ex. /fr/credit-immobilier/ -> credit-immobilier.webp. La même image sert pour FR / EN / AR.
